Project Title- 
Hybrid Restaurant Recommendation System.
A full-stack AI-powered restaurant recommendation system that provides personalized restaurant suggestions using a hybrid recommendation engine combining Content-Based and Collaborative Filtering.

Problem Statement-
Finding the right restaurant from thousands of available options can be overwhelming. Most users rely on random searches or reviews, which may not match their personal preferences.
This project aims to build a Hybrid Restaurant Recommendation System that recommends restaurants based on user preferences, cuisine, ratings, location, and price range by combining Content-Based Filtering and Collaborative Filtering techniques.

Planned Features-
